# 药师 · HonorAdvancedSettings

面向荣耀 MagicOS 11 的 LSPosed 模块：把系统 OTA 更新砍掉的液态玻璃补回来，并接管安装器、云端策略与高温限制。

## 支持范围

| 项 | 说明 |
| --- | --- |
| 机型 | 荣耀 Magic 系列（开发与实测机型：荣耀 Magic 11） |
| 系统 | MagicOS 11（Android 17），仅在 MagicOS 11 上实测 |
| 模块最低版本 | Android 13（minSdk 33） |
| 框架 | LSPosed，或 Vector 等兼容管理器 |
| ROOT | 部分功能需要（高温限制解除、云控配置清理、重启温控 / 云控作用域） |

在其他 MagicOS 版本上类名可能变化，Hook 未命中时功能静默失效，不会影响系统稳定。

## 功能

模块分为五组能力，全部在「药师」应用内以开关控制，配置跨进程同步。安装器线改开关即时生效，玻璃线改动需重启系统界面（应用内一键重启作用域）。

**液态玻璃**：还原被系统更新阉割的控制中心 / 通知中心液态玻璃，覆盖五条线。

| 功能 | 说明 |
| --- | --- |
| 系统界面 | 还原 LIQUID 材质位、强制 HIGH 机型渲染路径、材质类型改判（大方法 Hook，抗 AOT 内联） |
| 锁屏 | 锁屏通知卡片与快捷按钮与通知栏观感逐项对齐；静态壁纸经原厂模糊管线合成位图 |
| 通知横幅 | 横幅玻璃观感与通知栏一致，文字按背景对比度择优着色 |
| 桌面 | 桌面卡片与文件夹的模糊 / 饱和度 / 亮度，独立开关 |
| 相册 | 相册照片页工具栏的液态玻璃效果 |
| 精细调节 | 75 项参数按界面分组（系统 45、锁屏 25、桌面 3、总开关 2），100% = 不改动，可 0~200% 调节 |
| 分线开关 | 五条线独立开关；系统级底层钩子归总开关管辖，关闭分开关不会连带破坏底层 |

**安装器净化**：跳过联网安全检测与推广，覆盖 14.0.22.322 / 22.326 / 22.327 / 32.303 / 38.301 / 39.301 / 40.301 等版本。

| 功能 | 说明 |
| --- | --- |
| 安全检测净化 | 检测请求全拦、不读本地高风险依据、结果改写为安全，安装页只保留信息卡 / 取消 / 安装 |
| 广告与导流 | 拦截推广卡片、导流按钮、推荐位，以及广告点击 / 曝光 / 策略 / 详情 / 未展示上报 |
| 禁止联网 | 阻断安装器的推广与上报请求 |
| 安装包信息卡 | 展示版本 / 大小 / SDK / 架构；可关闭 |
| 允许降级安装 | 允许安装低于当前版本号的 APK |
| 安装提速 | 跳过「准备安装」阶段的免检与分流网络等待 |
| 匿名来源 | 无来源包名时静默放行，任何失败自动回退为可见可点的原厂弹窗 |
| 自适应钩子 | 类经 DexKit 字符串锚定位、方法经参数签名扫描定位，安装器 OTA 混淆重排后大概率免更新模块 |

**安全组件**

| 功能 | 说明 |
| --- | --- |
| 允许截屏 / 录屏 | 清除普通应用的 FLAG_SECURE；通知栏、状态栏等系统隐私窗口保留保护 |
| 屏蔽云控下发（双重保险） | 单一总开关，三份云控下发入口不再触发，PowerGenie 进程内云控落盘入口空操作（返回成功但不产生真实文件） |
| 屏蔽反诈采集上报 | 覆盖安全服务（securityserver）与感知服务（awareness）两个作用域，只放行机主围栏，其余默认拒绝 |
| 云控配置清理 | 备份 / 删除 / 恢复 `/data/cota/para` 下的性能与温控配置残留（需 ROOT） |

**高温限制解除（需 ROOT）**

高温时不弹「建议暂停使用」、不限屏幕亮度、系统热状态按正常上报，压制 PowerGenie 的 10 个性能限制执行点（游戏锁帧 / 降画质 / 锁亮度 / 帧率检查与上报），高温自动关机不再触发。默认关闭，开启前二次确认。内核调度与降频不受影响。

**状态、诊断与更新**

| 功能 | 说明 |
| --- | --- |
| 激活状态 | 首页标题下显示状态点：绿色已激活、红色未激活、黄色无法确认 |
| 作用域自检 | 各宿主进程启动时自证一次，未生效时点名具体作用域，生效后自动隐藏 |
| 重启作用域 | 可多选批量重启：系统界面 / 相册 / 安装器 / 桌面 / 桌面模式 / 温控服务 / 反诈服务 / 感知服务 |
| 诊断日志与报告 | 一键导出设备、root 方案、开关快照、钩子挂载结果与日志尾部到「下载」目录 |
| 检查更新 | 打开应用时自动检查（一小时最多一次，仅发现新版本才提示），也可手动检查 |

## 安装与启用

1. 安装 APK，在 LSPosed / Vector 中启用模块，作用域按应用内推荐勾选。
2. 打开「药师」应用，按需开关各功能。
3. 玻璃线、反诈 / 感知相关改动后，用应用内「重启作用域」重启对应宿主（或重启手机）；安装器线即时生效。
4. 首次使用建议在「关于」页导出一次诊断报告，确认各作用域已加载。
5. **不要与 HonorLiquidGlassRestore、HonorInstallerPurify 同时启用**（功能重叠会导致钩子重复挂载）。迁移时先禁用并卸载旧模块。

## 环境要求

- 已 root 的荣耀 MagicOS 11 设备，安装 LSPosed 或兼容管理器（Magisk / KernelSU / ReSukkiSU 等方案均可）。
- 必需作用域：系统界面、荣耀桌面、相册、安装器、系统框架。
- 按需作用域：高温限制解除需温控服务（powergenie）与 iaware；安全组件需 securityserver 与 awareness。安装包已声明全部推荐作用域，管理器通常可一键应用。
- 没有 root 时：高温限制解除只剩弹窗屏蔽生效（属性写入、PowerGenie 压制、云控清理不可用），云控配置清理与相关作用域重启不可用；其余功能正常。

## 已知限制

- 仅在 MagicOS 11 上实测，其他版本可能整体静默失效。
- 安装器净化覆盖多个安装器版本，除当前运行时版本外，其余按静态反编译核对适配，未逐版装机验证。
- 广告点击与曝光的 URL 由服务端下发，静态只能核到调用点。
- 相册、安装器、桌面模式的进程名由 manifest 推断，未逐项实际运行验证；桌面模式无样本。
- 感知服务部分的挂载数量未逐机型上机确认。
- 液态玻璃效果依赖系统渲染路径，部分界面由系统自行判定材质，可配合「强制液态」开关。
- 安全服务（securityserver）在部分设备上存在开机 `libdexkit.so` 崩溃记录，属既有问题，与本模块改动无关。

## 隐私

本模块完全运行于本机，不获取、不上传任何隐私内容：

- 不读取通讯录、短信、通话记录、位置、相册、麦克风、摄像头、剪贴板。
- 不收集设备标识，不碰账号信息；没有埋点统计、没有第三方 SDK。
- 开关与参数只保存在本机应用私有目录，卸载即删除。
- 唯一声明的网络权限用于检查更新（访问 GitHub 公开接口），只有你手动点击或应用启动时的自动检查会用到。
- 诊断报告只在用户点击时生成，存在本机「下载」目录，发不发由你决定。

## 从源码构建

主构建链为 Gradle（Kotlin + Compose + miuix）：

```
gradle assembleRelease
```

签名凭据放在 `local.properties`（`STORE_PASS` / `KEY_PASS`，不入库），JDK 21 与 Android SDK 由 `local.properties` 的 `sdk.dir` 指定。R8 混淆与资源收缩默认开启，Xposed 入口 / Provider / 钩子类的 keep 规则见 `app/proguard-rules.pro`。`module/` 内保留 1.4.22 的纯 Java 源码与旧免 Gradle 构建链，仅作历史归档。

主要目录：`app/src/main/java/io/github/voreulch/honoradvanced/`（Hook 与配置）、`app/src/main/kotlin/`（模块界面）、`app/src/main/assets/`（入口声明与图片资源）。
