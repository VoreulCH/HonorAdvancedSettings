# 药师 · HonorAdvancedSettings

面向荣耀 MagicOS 11 的 LSPosed 模块：把系统更新砍掉的液态玻璃补回来，并接管安装器、云控、短信与高温限制。

模块已整体重写到 **LSPosed API 102（libxposed 新接口）**，旧 Xposed API 版本（3.8.x）不再维护。

> **AI 生成声明**：本项目由大语言模型在人类指导下生成并迭代维护，包括逆向分析、Hook 代码、构建流水线与文档。代码未经人工长期审计，请自行评估风险后使用；欢迎人工审查与 PR。
>
> **源码仓库**：https://github.com/VoreulCH/HonorAdvancedSettings
> 本页同时作为 LSPosed 官方发布镜像（用于 modules.lsposed.org 索引与分发）；源码、issue、讨论请走源码仓库。

## 支持范围

| 项 | 说明 |
| --- | --- |
| 机型 | 荣耀 Magic 系列（开发与实测机型：荣耀 Magic 11） |
| 系统 | MagicOS 11（Android 17），仅在 MagicOS 11 上实测 |
| 模块最低版本 | Android 13（minSdk 33） |
| 框架 | LSPosed（**需支持 API 102**，老框架在模块列表里看不到本模块），或 Vector 等兼容管理器 |
| ROOT | 部分功能需要（高温限制、低电量限制、温控限制、云控清理、冻结 / 解冻、允许截屏、重启作用域） |

在其他 MagicOS 版本上类名可能变化，Hook 未命中时功能静默失效，不会影响系统稳定。

## 安装与启用

1. 完成 root（Magisk / KernelSU / ReSukiSU 等方案均可），安装**支持 API 102 的 LSPosed**。
2. 在 LSPosed 里启用「药师」，作用域按安装包声明的推荐列表一键套用：共 **47 行**（46 个包 + `system`）。
3. **老用户升级后要手动确认一次作用域**：517 起新增搜狗输入法 `com.sohu.inputmethod.sogou.honor`，LSPosed 不会替你自动勾上，没勾的话「搜狗输入法净化」不生效。
4. 打开「药师」，首页标题下看激活状态：绿点 = 已激活且作用域齐；黄点 = 已激活但有已装的目标没授权（或框架没连上）；红点 = 未激活。点问号看缺哪几个作用域。
5. 玻璃线、安全组件、温控相关改完，用「重启作用域」（需 ROOT）重启对应宿主，或重启手机；安装器线改开关即时生效。
6. **不要与 HonorLiquidGlassRestore、HonorInstallerPurify 同时启用**（功能重叠会导致钩子重复挂载）。迁移时先禁用并卸载旧模块。

## 主要功能

全部在「药师」应用内以开关控制，配置跨进程同步。首页按四张卡分组，另有一页「关于」。

### 液态玻璃

还原被系统更新阉割的控制中心 / 通知中心液态玻璃。

| 功能 | 说明 |
| --- | --- |
| 六条线 | 系统界面、灵动岛、锁屏、横幅、桌面、相册，各自独立开关；系统级底层钩子归总开关管辖，关掉分开关不会连带破坏底层 |
| 横幅文字反色 | 按横幅实际背景对比度择优着色，浅色横幅不再被刷成白字 |
| 精细调节 | **130 项**参数按界面分组，100% = 不改动，可 0~200% 调节 |
| 参数管理 | 一键恢复官方原始参数 / 恢复作者特调参数，导出与导入 json（只含液态玻璃这一摊） |

### 系统净化

| 功能 | 说明 |
| --- | --- |
| 安装器净化 | 跳过联网安全检测与指纹验证、禁止联网、隐藏推广卡片与导流按钮、安装包信息卡、允许降级安装、跳过「准备安装」等待；覆盖 **15 个挂载域**，支持 14.0.22.322 / 22.326 / 22.327 / 32.303 / 38.301 / 39.301 / 40.301 等版本 |
| 安装器自适配 | 按安装器 APK 指纹判断是否已适配，可发起一次适配并回读每个域挂上了几条；安装器更新后自动回到「未适配」 |
| 短信净化 | 摘掉详情页推广卡片下方那排按钮（含查询余额），精简发送框；两个开关默认关 |
| 搜狗输入法净化 | 剪贴板上限放开到 99999、上报与推广拦截、云端联想与云输入断网 |

### 系统综合

| 功能 | 说明 |
| --- | --- |
| 屏蔽通知回避 | 播放音乐时来消息不再压低音乐音量，闹钟不受影响 |
| 屏蔽高温限制（ROOT） | 高温时不弹提示、不限亮度、热状态按正常上报，压制 PowerGenie 温控；默认关闭，开启前二次确认 |
| 解除设备名称限制 | 不再拦违禁词，长度放宽到 999 字符 / 3996 字节，文本识别不再出网 |
| 解除低电量限制（ROOT） | 系统内部全部按「未开省电」处理（动画、模糊、振动、定位、后台联网等） |
| 低电量放开闪光灯 | 电量见底时不再禁止开闪光灯，已点亮的也不会被强制关掉 |
| 解除温控限制（实验） | 高温时不再压低充电电流、不降亮度与分辨率、不锁帧率 |
| 桌面文件夹调整 | 只改文件夹展开后的网格：每行图标数、每竖图标数、横向 / 纵向间距（80%~120%） |
| 冻结应用 / 解冻应用（ROOT） | `pm disable-user` 冻结保留数据，或列出处于冻结状态的应用后解冻；支持搜索、系统 / 用户分页 |

### 安全组件

| 功能 | 说明 |
| --- | --- |
| 屏蔽系统安全组件 | 一重只断上报通道、本地功能保留；二重让检测本身不运行；两层独立可叠加；覆盖 **40 项组件表**（含反诈防护） |
| 云控 / 清理 | 六个入口：屏蔽性能参数读取与写入、按组屏蔽云控下发与上传、清理与恢复云控文件（ROOT）、系统云控移除与还原（ROOT） |
| 允许截屏（ROOT） | 清除窗口 `FLAG_SECURE`，让原本一截就黑屏的页面正常截图录屏；系统隐私窗口保留保护 |

云控上报只有一个出口，由「上传」那一项单独驱动；组勾选只拦下发，不管上传。

### 状态、诊断与其它

| 功能 | 说明 |
| --- | --- |
| 激活状态 | 首页标题下三态色标 + 问号弹窗列出缺失作用域 |
| 重启作用域（需 ROOT） | 按组勾选批量重启，十组：液态玻璃 / 系统界面 / 安装器净化 / 反诈防护 / 温度限制 / 云控屏蔽 / 短信净化 / 搜狗输入法净化 / 系统框架 / 系统安全组件；同一进程只重启一次 |
| 待重启提示 | 改了需要重启才生效的项时，首页出现「待重启」入口，可选软重启（仅系统框架）或整机重启 |
| 诊断日志导出 | 一键导出设备、root 方案、开关快照、每个宿主的钩子挂载回执与日志尾部到「下载」目录；诊断记录有总开关，关掉就不再记录和导出 |
| 检查更新 | 打开应用自动检查（一小时最多一次，仅发现新版本才提示），也可手动检查 |

## 风险提示（先读这一段）

- **需要 ROOT 的项**：高温限制、低电量限制、温控限制、云控清理、冻结 / 解冻应用、允许截屏、重启作用域。
- **卸载模块前先关掉「屏蔽高温限制」**，否则系统会持续按正常温度上报。
- **冻结系统应用有开不了机的风险**，冻结页会对危险项单独标红；不确定就先用用户应用试。
- **解除低电量限制、低电量放开闪光灯、解除温控限制**都会让耗电与发热明显上升，闪光灯长时间点亮还会发热。
- **云控清理会删掉 `/data/cota/para` 下的文件**，动手前先在应用内做一次备份。
- 允许截屏会让原本受保护的页面变得可截，只在你清楚后果时开。

## 已知限制

- 仅在 MagicOS 11 上实测，其他版本可能整体静默失效。
- 安装器净化覆盖多个安装器版本，除当前运行时版本外，其余按静态反编译核对适配，未逐版装机验证。
- 广告点击与曝光的 URL 由服务端下发，静态只能核到调用点。
- 液态玻璃效果依赖系统渲染路径，部分界面由系统自行判定材质，可配合「强制液态」开关。
- 桌面文件夹间距只支持 80%~120%；盘上残留更大值（例如旧版试过的 140）会按 100% 生效并显示 100%。
- 改了需要重启才生效的项后，未重启前界面显示的是「已改」，不是「已生效」。
- 安全服务（securityserver）在部分设备上存在开机 `libdexkit.so` 崩溃记录，属既有问题，与本模块改动无关。

## 隐私

本模块完全运行于本机，不获取、不上传任何隐私内容：

- 不读取通讯录、通话记录、位置、相册、麦克风、摄像头；短信与搜狗输入法的处理全在本机完成，内容不外发。
- 不收集设备标识，不碰账号信息；没有埋点统计、没有第三方 SDK。
- 开关与参数只保存在本机应用私有目录，卸载即删除。
- 唯一声明的网络权限用于检查更新（访问 GitHub 公开接口），只有手动点击或启动时的自动检查会用到。
- 诊断报告只在用户点击时生成，存在本机「下载」目录，发不发由你决定。

## 版本号规则

- 500 起使用新规则：`versionCode = 主版本 × 100 + 次版本 × 10 + 修订`，`versionName = 主.次.修`，两边必须同步，禁止单边改。
- 末位封顶 9，再 +1 进一位（`509 → 510` 即 `5.0.9 → 5.1.0`）。
- 336 / 3.8.36、337 / 3.9.0 属旧三段式（3.x），只对历史版本有效。
- 当前源码版本：**526 / 5.2.6**。

## 从源码构建

主构建链为 Gradle（Kotlin + Compose + miuix），JDK 21：

```
gradle assembleRelease
```

- 依赖 `io.github.libxposed:api:102` / `:service:102` / `:interface:102`（`app/libs` 下的 jar），只用 `compileOnly`，不进包。
- 先出未签名包（`-PunsignedBuild`），再用 apksigner 以 `--min-sdk-version 24` 同时写 v2 + v3。
- 签名凭据不入库、不进快照：签名材料放在仓库外的独立目录，构建时临时读取。
- R8 混淆与资源收缩默认开启，Xposed 入口 / Provider / 钩子类的 keep 规则见 `app/proguard-rules.pro`。
- 主要目录：`app/src/main/java/...`（Hook、配置与回执）、`app/src/main/kotlin/...`（模块界面）、`app/src/main/resources/META-INF/xposed/`（入口声明与 `scope.list`）、`app/src/main/assets/`（图片资源）。
